# Fashion E-Commerce Store

A responsive fashion e-commerce frontend built with HTML, CSS and JavaScript.

## Features
- Responsive fashion store UI
- Product catalog and categories
- Size and color variants
- Wishlist
- Shopping cart
- Quantity controls
- Automatic subtotal, shipping and total calculation
- Checkout form validation
- Order confirmation
- localStorage persistence

## Run
Open `index.html` in a modern browser.

## Note
This is a frontend/demo checkout. Real payment processing and secure server-side order handling require a backend, HTTPS, authentication, database, and payment gateway integration.
